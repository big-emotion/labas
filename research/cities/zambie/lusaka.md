# Lusaka, Zambia

> Curated 2026-11-14. Raw items for Là-bas — not published text. Testimonies are anecdotes, not data.

Currency note: USD amounts are converted at the dossier's rate of **1 USD ≈ 0.92 EUR**. For kwacha, the dossier's own figure (about ZMW 25 per USD) was only inferred from trade data, so this file uses a dated market rate instead: **ZMW 19.78 per USD** (Rio Times, close on 2026-11-11). Combined with 0.92, that gives **1 EUR ≈ ZMW 21.5** (1 ZMW ≈ €0.0465). Zambia Monitor gives ZMW 20.37 at the end of October 2026, so EUR values are approximate to within a few percent. The shared web-search budget had run out before this file was started, so no keyword searches were run. All items come from pages fetched directly. Numbeo returned HTTP 429, and its figures appear only where Expat.com reproduces them.
