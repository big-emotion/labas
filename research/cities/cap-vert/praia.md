# Praia, Cape Verde

> Curated 2026-11-14. Raw items for Là-bas — not published text. Testimonies are anecdotes, not data.

Currency note: EUR equivalents use the dossier rate **1 EUR = 110.265 CVE** (fixed euro peg, Wikipedia "Cape Verdean escudo", accessed 2026-11-14), rounded. Sources quoting only USD are converted at **US$1 ≈ 97 CVE** (Wikivoyage Cape Verde, rate dated July 2026), so US$1 ≈ €0.88. Research-depth caveat: the shared web-search budget ran out after two searches, so this file relies on pages opened directly (official advisories, Expat.com guide and forum, Wikivoyage, Wikipedia, local media, cost aggregators). No Cape Verdean property portal could be opened, so there are no dated listing prices for Praia.
